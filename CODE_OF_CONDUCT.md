# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to every space the project uses, including issues, pull requests and discussions.

## Reporting

To report a violation, send a private message to the maintainer, [@TristanHottier](https://github.com/TristanHottier), on GitHub. If you prefer, use the private form under the repository's Security tab ("Report a vulnerability"), and say that the report is about conduct.

The maintainer applies the enforcement guidelines of the Covenant and keeps reports confidential.
