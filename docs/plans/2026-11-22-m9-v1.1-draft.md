## Scope

**In:**
- A discoverable way to place, move and clear cursor B, by mouse and by keyboard.
- A full visual redesign of the web app, in two passes:
  1. **Baseline:** a conventional modern web-app look, built fast from familiar patterns. Tristan's words: "the usual AI slop look". For example: a clean sans UI font, a neutral scale, one accent, rounded controls, subtle borders and elevation, an icon set, a top bar, and a tool rail with icons and tooltips.
  2. **Distinctive pass:** impeccable runs on that baseline.
     - `critique` first.
     - Then whichever of `bolder`, `quieter`, `colorize`, `typeset`, `layout` and `delight` the critique calls for.
     - Then `audit`, fixes and `polish`.
     - The goal is to move it away from the generic look into something that fits an engineering tool.
- Layout and control changes that serve the redesign: header and tool rail, panel structure, icons, control styling, empty states. This covers C3, C5, C9, C11, C12 and C13 if the new design addresses them.

**Out:** new features, engine changes, file-format changes, new analyses or devices. Copy changes only where the new layout needs a label, tooltip or hint.

## Decisions for the planning session

The planning session should put these to Tristan, grill-me style, with a recommended answer for each, and record them in the plan or in the new ADR.

1. **Cursor interaction.** Options:
   - (a) The first click places A, the second places B, and later clicks move the nearer cursor.
   - (b) An A/B segmented toggle above the plot picks which cursor the next click moves.
   - (c) Draggable cursor handles on the plot.
   - Also decide how to remove a cursor, and the keyboard path (for example, arrow keys move the active cursor by one sample while the plot is focused).
   - Shift+click should keep working in every option.
   - Recommended: (b) plus drag handles, with a short visible hint.
2. **Reference look for the baseline:** for example Linear, Vercel, Figma or GitHub Primer. Pick one so the "generic" pass is coherent.
3. **Fonts:** keep system stacks, or self-host a UI font (for example Inter or Geist) and a mono font. Check the licence and the Lighthouse cost; there is no CDN, so fonts must be self-hosted.
4. **Icons:** for example Lucide (ISC licence) or Phosphor (MIT). The schematic symbols stay as drawn (IEC, ADR 0007).
5. **Default theme:** keep following the OS, or default to dark.
6. **Relation to ADR 0012:** the new ADR supersedes its visual sections (palette, type, controls). The brand mark, token architecture and 60/30/10 role-order ruling carry over.
7. **Which M8 "Findings not fixed" to take in:** C3, C4, C5, C9, C11, C12, C13.
8. **Inspector default (C4):** whether Analyses should come first when nothing is selected. This is a behaviour change, so it is Tristan's call.
