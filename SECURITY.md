# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a vulnerability

Please report vulnerabilities privately. Don't open a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include the version, the steps to reproduce and the impact you see.

## Scope

Nodal is a static site hosted on GitHub Pages. It has no server and no accounts. Projects are stored locally in your browser (IndexedDB) or in `.nodal.json` files you export, and nothing is sent anywhere. Reports about the app itself, such as malformed project files, the build or the deployed site, are in scope.
